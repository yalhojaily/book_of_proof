# كتاب البرهان: موقع مصاحب تفاعلي

موقع عربي مصاحب لكتاب **Book of Proof** (الطبعة الثالثة) لريتشارد هاموك. يتبع ترتيب الكتاب: 4 أجزاء و14 فصلاً، ولكل قسم صفحة فيها شرح وأدوات تفاعلية وأمثلة محلولة وتمارين بتلميحات.

**الموقع:** https://yalhojaily.github.io/book_of_proof/

## الحالة

| الفصل | الحالة |
|---|---|
| 1. المجموعات (1.1–1.10) | ✅ مكتمل |
| 2–14 | دليل قراءة بأرقام الصفحات، والشروح قيد الإعداد |

## التشغيل محلياً

```bash
npm install
npm run dev      # http://localhost:4321/book_of_proof/
npm run build    # الناتج في dist/
```

## البنية

```
src/
  data/book.ts                 هيكل الكتاب: الأجزاء والفصول والأقسام وأرقام الصفحات
  data/quiz-ch1.ts             أسئلة الاختبارات السريعة للفصل 1
  content/lessons/01-sets/     درس لكل قسم (MDX)
  components/pedagogy/         صناديق الحدس والتعريف والمثال والتمرين والتلميح
  components/widgets/          الأدوات التفاعلية (React)
  lib/setexpr.ts               محلّل تعابير المجموعات (A ∪ B)' ...
  pages/                       الصفحة الرئيسية، صفحة الفصل، صفحة الدرس
```

### إضافة فصل جديد

1. أنشئ مجلداً في `src/content/lessons/` وملف MDX لكل قسم، مع `chapter` و`section` في الترويسة.
2. غيّر `available: true` للفصل في `src/data/book.ts`.
3. صناديق الشرح (`<Definition>` و`<Example>` و`<Reveal>` وغيرها) متاحة في كل درس دون استيراد. الأدوات التفاعلية تُستورد وتُستخدم مع `client:visible`.

## التقنيات

Astro مع MDX، وجزر React للأدوات التفاعلية، وKaTeX للرياضيات (يُعرض وقت البناء). يُنشر تلقائياً على GitHub Pages عند كل دفع إلى `main`.
